# Financial-Analysis-Capstone-Project
This project aims to track actual vs budget revenue and expenses. It also analyses the cost per employee and brings the expenses to control.

1) Purpose:
This Financial Data Analysis dashboard consists of 4 sections, giving details about the KPIs like revenue, expenses, profit, budget and expense variances over both the years. The rest of the pages consist of details regarding revenue performance, customers & vendors, along with workforce efficiency.

2) Tech Stack:
* Python for EDA & basic visualization to understand the distributions.
* Power BI desktop for the main visualization.
* Power Query for minor data cleaning.
* DAX - used to create calculated measures, to create calender table for time intelligence.
* Data Modelling - Relationships established among various tables.
* File Format - .pbix for development, .png for dashboard preview.

3) Data Source: This is a project given by the institute, so the dataset has been provided by them.
